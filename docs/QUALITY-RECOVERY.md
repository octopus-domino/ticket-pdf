## Диагностика Infra

- Phase 1 под общей нагрузкой зафиксировала два `TimeoutExpired`. Изолированный повтор исходных тестов прошёл за 32,6 с. В Phase 1.1 полный запуск исходного кода дал 18/21. Import failure прошёл, legacy build снова упал, ещё два длинных сценария завершились по дедлайну. В fixture legacy build к тому моменту fake Docker выполнил 58 вызовов, включая команды восстановления. Предел 120 секунд достигался в разных стадиях. Причина его превышения остаётся под наблюдением.
- Синтетический запуск старого `subprocess.run(capture_output=True)` на Windows вернул таймаут 1,5 с через 3,27 с. Самостоятельный дочерний Python-процесс успел записать маркер после истечения дедлайна. Новый регрессионный тест запускает такой же сценарий с файловыми дескрипторами и проверяет, что дочерний процесс стартовал и файл после таймаута не появился. `infra-process-before.log`, `infra-process-after.log`.
- `mkdtemp` создаёт для каждого теста отдельные каталог, `state.json`, Bash-скрипты и файл псевдоблокировки. Путь к fixture передаётся через отдельное окружение дочернего процесса. Полный набор прошёл 22/22 после исправления. Два целевых случая повторно прошли в обратном порядке и параллельно в независимых процессах. Синтетическая проверка дерева процессов дополнительно прошла при отдельном повторе.
- Выполнялся Windows Git Bash и PowerShell. POSIX-ветвь основана на отдельной process group. Для проверки целевого Linux нужен обычный Linux runner. Compose валидирован без запущенного Docker daemon. Подтверждение на целевых ОС и реальные миграции/restore остаются отдельной задачей.

## Открытые задачи

- **P1.** Сценарии старого конструктора прогулок Editor ожидают поиск, выбор готовых прогулок или фотографий внутри формы маршрута. Текущий `RoutePlacePanel` передаёт построение в отдельное приложение, а контракт передачи сохраняет точки, описания, ссылку на источник и геометрию. Требуется согласовать передачу фотографий, атрибуции и сценарии каталога прежде, чем менять проверяемый контракт. Условия тестов сохранены.
- **P1.** Проверить целевую инфраструктуру на изолированном Linux с Docker и PostGIS. Включить нагрузку с ограниченным CPU, отдельно замерить команды fake Docker и повторить безопасный отказ миграции и сборки по журналу стадий. Проверить резервную копию восстановлением в отдельную БД.

Откат изменений качества независим по репозиториям. В Editor можно откатить блоки типов, фокуса и браузерных fixtures отдельно. В Journey изменение жизненного цикла карты отделено от конфигурации тестов. В Infra изменение касается только тестового runner. Изменения схемы БД и форматов данных не требуются.
