# Исходные решения для планировщика

- Карта CoDoc использует MapLibre GL. Переиспользуем этот стек в планировщике, чтобы сохранить существующие стили карты и механизм снимков. Самостоятельная прогулка использует Leaflet.
- В CoDoc уже есть короткие ссылки для серверных публикаций. Базовый сценарий нового планировщика хранит черновик в браузере и открывает общий доступ по явной ссылке. Серверный режим с TTL рассматривается отдельно.
- Excel-импорт остаётся в действующих сценариях. Планировщик подключается отдельной веткой пользовательского интерфейса под выключенным по умолчанию флагом.
- Фронтенд использует React и компонентное состояние. Для планировщика одна модель поездки питает карту, список и сводку. Используем существующие стили и компоненты CoDoc, сохраняем мобильные сценарии.
- Бэкенд использует Spring Boot 3.3.4 с целевой Java 17. В GitHub Actions есть проверки качества. Архитектурные правила и Javadoc добавляются по мере выделения новых пакетов.
