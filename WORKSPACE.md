# Сервисы CoDoc

- `document-service/` — приложение `ticket-pdf`, шаблоны, модели, генерация, PDF и документы публикаций. Порт 8080.
- `routing-service/` — построение дорог, резервные провайдеры, геопоиск и каталог прогулок. Порт 8093. [Контракты и настройки](routing-service/README.md)

План изменения границ был таким:

1. Зафиксировать прежний формат геометрии и ошибок и вынести расчёт дорог за порт провайдера.
2. Перенести поиск мест и каталог прогулок. Публикация сохраняет ссылки на печатные материалы. Фотографии регистрируются через HTTP в конструкторе.
3. Переключить редактор, веб-прогулки и Android-клиент на новые адреса.
4. Разнести схемы PostgreSQL и базы H2. Обновить сборку, запуск и проверки в ticket-infra.

`mvn clean verify` собирает и проверяет оба проекта. Для сборки одного приложения используйте `mvn -pl document-service verify` или `mvn -pl routing-service verify`.

# Шаблоны и документы в папках

`GET /api/workspace/tree` возвращает документы и шаблоны в одном дереве. Узел `type: template` открывает существующий шаблон, а не отдельную копию документа. Шаблоны без папки, включая созданные до обновления, видны в корне.

`POST /api/templates` принимает необязательный `folderId`. Сервер проверяет принадлежность папки пользователю. Сохранение содержимого через `PUT /api/templates/{id}` сохраняет папку; для перемещения используется `PUT /api/templates/{id}/parent` с `parentId` (null — корень). Удаление папки удаляет её документы и шаблоны, включая вложенные папки.

В таблицу `templates` добавлена nullable-колонка `folder_id VARCHAR(36)`. При стандартной конфигурации проекта `ddl-auto: update` Hibernate добавляет её при запуске. Если автоматическое обновление отключено, примените `document-service/src/main/resources/db/upgrade-template-folders.sql` до запуска новой версии.

Для генерации без схемы отправляется один элемент `items: [{"inlineValues": {}}]`. Схема и наборы значений необходимы только для персонализации. Полноценная проверка сценария с папками, доступом другого пользователя и генерацией включена в `DocumentFlowTest`.
