# Шаблоны и документы в папках

`GET /api/workspace/tree` возвращает документы и шаблоны в одном дереве. Узел `type: template` открывает существующий шаблон, а не отдельную копию документа. Шаблоны без папки, включая созданные до обновления, видны в корне.

`POST /api/templates` принимает необязательный `folderId`. Сервер проверяет принадлежность папки пользователю. Сохранение содержимого через `PUT /api/templates/{id}` сохраняет папку; для перемещения используется `PUT /api/templates/{id}/parent` с `parentId` (null — корень). Удаление папки удаляет её документы и шаблоны, включая вложенные папки.

В таблицу `templates` добавлена nullable-колонка `folder_id VARCHAR(36)`. При стандартной конфигурации проекта `ddl-auto: update` Hibernate добавляет её при запуске. Если автоматическое обновление отключено, примените `src/main/resources/db/upgrade-template-folders.sql` до запуска новой версии.

Для генерации без схемы отправляется один элемент `items: [{"inlineValues": {}}]`. Схема и наборы значений необходимы только для персонализации. Полноценная проверка сценария с папками, доступом другого пользователя и генерацией включена в `DocumentFlowTest`.
